
### AHB to APB Bridge Verification IP (VIP)

This project involves the **functional verification** of an **AHB to APB Bridge** using **SystemVerilog** and **UVM (Universal Verification Methodology)**. The bridge converts transactions between the high-speed AHB bus and the lower-speed APB bus, commonly used in SoC designs.

#### Key Features:
- Developed a reusable and scalable **UVM-based testbench**.
- Used **constraint-based random testing** to generate a wide range of test scenarios.
- Applied **SystemVerilog assertions** for protocol checking and error detection.
- Implemented **functional coverage** to measure and ensure verification completeness.

#### Verification Goals:
- Validate proper data and control signal translation between AHB and APB.
- Ensure compliance with protocol specifications.
- Identify edge cases and verify robustness of the design.
